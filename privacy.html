Privacy Policy

Calendar MCP Server — last updated 9 October 2026

Calendar MCP Server is a personal, single-user application operated by Srdjan Kojic. It is used only by its author, on his own computer, with his own Google account. It is not offered to, installed by, or used by anyone else.

What data is accessed

The application requests access to Google Calendar. With that access it can read calendar events, create and modify events, delete events, and check free/busy availability. It accesses only the calendars belonging to the single Google account that authorised it. It does not access Gmail, Drive, Contacts, or any other Google service.

How data is used

Calendar data is used solely to answer the operator's own requests — showing upcoming events, finding free time, and creating or amending appointments. It is not used for advertising, profiling, analytics, training, or any form of automated decision-making.

Where data is stored

The application has no server and no database. Calendar data is requested from the Google Calendar API at the moment it is needed and is not retained afterwards. The only thing stored persistently is the OAuth token, which is written to a file on the operator's own computer and never leaves that machine.

Sharing

No data is shared with any third party. Nothing is sold, transferred, or disclosed to anyone. The only network connection the application makes is to Google's own APIs.

Retention and deletion

Because no calendar data is retained, there is nothing to delete on the application's side. Access can be withdrawn at any time by revoking the application at myaccount.google.com/permissions, or by deleting the local token file, which immediately ends all access.
