Calendar MCP Server

A personal Google Calendar integration for my own account.

This is a single-user application. It lets an assistant running on my own computer read and manage the events on my personal Google Calendar — listing what is coming up, creating and updating events, checking when I am free, and sending meeting invitations.

It is not a product, it is not distributed, and it has no users other than me. It runs locally on my machine and connects directly to the Google Calendar API. It is built on the open-source google-calendar-mcp server.

Access requested

The application requests access to Google Calendar in order to read and write events on my own calendar. No other Google data is accessed.
